# Quote Generator

A simple Python project demonstrating virtual environments.

The main file stores a list of tuples: quotes and their associated authors. On each run, using built-in modules, the program randomly selects a pair and prints the results.

## Set-up

1. Clone this repo
2. Create virtual environment: `python -m venv venv`
3. Activate: `source venv/Scripts/activate`
4. Install dependencies: `pip install -r requirements.txt`
5. Run: `python main.py`
