# Grade Tracker

This Python project reads a CSV file containing student data (name and grade by subject [math, science, english, history]) and produces a grade report/class summary as a text file (.txt), including:

- Total Students
- Class Average
- Highest Average
- Lowest Average
- Letter Grade Distribution
- Individual Student Summaries (Name, Average, Letter Grade)

## Setup

1. Clone this repo.
2. Ensure the student data file is located at data/students.csv
3. Run: `python grade_tracker.py`

(No virtual environment or dependencies required.)
